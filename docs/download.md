# Download

!!!tip
**SpliceKit v4 now requires at least ONE paid LateNite application installed from the Mac App Store.**\
\
**However, SpliceKit remains open source - and you can build it yourself.**\
\
The cheapest options are [ScriptStar](https://scriptstar.fcp.cafe), [Fast Collections](https://fastcollections.fcp.cafe), [Gyroflow Toolbox](https://gyroflowtoolbox.fcp.cafe), [LUT Robot](https://lutrobot.fcp.cafe), [News Import](https://newsimport.fcp.cafe), [Recall Toolbox](https://recalltoolbox.fcp.cafe) and [Transfer Toolbox](https://transfertoolbox.fcp.cafe) - all **USD$9.99**.\
\
You can find a list of all LateNite's applications on the [Mac App Store](https://apps.apple.com/au/developer/latenite-films-pty-ltd/id1652018641).
\
All LateNite's applications on the Mac App Store support Family Sharing, and offer a reduced price on the Apple School Manager for volume purchases.\
!!!

You can download the latest **SpliceKit** on [GitHub](https://github.com/latenitefilms/SpliceKit/releases).

You can find the source code for the LateNite fork on [GitHub](https://github.com/latenitefilms/SpliceKit).

You can find the original source code by Brian Elliott Tate on [GitHub](https://github.com/elliotttate/SpliceKit).
